<h2><a href="https://www.geeksforgeeks.org/problems/add-two-fractions/1">Add two fractions</a></h2><h3>Difficulty Level : Difficulty: Basic</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 14pt;">Given four integers <strong>num1</strong>, <strong>den1</strong>, <strong>num2</strong>, and <strong>den2</strong>, representing two fractions num1/den1 and num2/den2, find their sum and return the resulting fraction in its simplified form.</span></p>
<p><span style="font-size: 14pt;">Return the answer as an array of two integers:</span></p>
<ul>
<li><span style="font-size: 14pt;">The first element represents the numerator.</span></li>
<li><span style="font-size: 14pt;">The second element represents the denominator.</span></li>
</ul>
<p><span style="font-size: 14pt;"><strong>Note: </strong>The driver will print the result in the format num/den.</span></p>
<p><strong><span style="font-size: 14pt;">Examples :&nbsp;</span></strong></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>num1 = 1, den1 = 500, num2 = 2, den2 = 500
<strong>Output:</strong> [3, 500]
<strong>Explanation</strong>: </span><span style="font-size: 14pt;">In this test case 1/500 + 2/500 = 3/500.</span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>num1 = 1, den1 = 6, num2 = 1, den2 = 3
<strong>Output:</strong> [1, 2]
<strong>Explanation</strong>: </span><span style="font-size: 14pt;">1/6 + 1/3 = 1/6 + 2/6 = 3/6 = 1/2.</span></pre></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Mathematics</code>&nbsp;
